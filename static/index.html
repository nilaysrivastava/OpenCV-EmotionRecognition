RESEARCH NOTES / 01

About the model.

This project uses Nilay’s own residual CNN trained from scratch on FERPlus. No pretrained emotion-recognition weights are used.

The sample portrait is a public-domain NASA photograph of Eileen Collins, distributed by scikit-image. Held-out metrics describe the saved model’s test run. They do not measure accuracy for every person, camera or setting.
