# Expression Atlas — Signal Console

Purpose: make a personally trained vision model inspectable through portraits, camera frames, score distributions and reproducible evaluation.

Direction: a dark technical instrument, distinct from Voib’s warm editorial style. Midnight navy surfaces, a restrained engineering grid, cobalt measurement marks and orange input/output highlights. Barlow Condensed headings pair with IBM Plex Sans controls and IBM Plex Mono measurements. All fonts are self-hosted. Fine face outlines and a strong classification panel make the model’s work visible without decorative fake statistics.

Use real model scores, real face regions, measured inference time and archived test results. The evaluation area distinguishes annotation protocols, displays per-class scores and exposes dataset coverage. The camera is opt-in, cancellable and stoppable; images remain in memory. Keyboard controls, visible focus, readable error states, reduced motion and a responsive console are part of the interface.
